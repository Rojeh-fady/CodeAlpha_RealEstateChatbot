# 🏢 PrimeEstate AI Assistant — Cloud-Based Real Estate Chatbot

An AI-powered commercial real estate concierge chatbot built with **Python**, **Streamlit**, and **Natural Language Processing (NLP)**. Designed for cloud deployment, property inquiries, budget estimation, scheduling site viewings, and lead capture.

Developed for **CodeAlpha Cloud Computing Internship — Task 4**.

---

## 🌟 Key Features & Highlights

- **100% Free & Standalone:** No API keys, external tokens, or paid third-party services required.
- **Dynamic Intent Recognition:** Weighted regex pattern matching and entity extraction for budgets, locations, property types, and financing queries.
- **Dynamic Calculation Engine:** Computes price statistics, loan/mortgage payments, and property matching scores dynamically.
- **Lead Capture & Filters:** Interactive UI with sidebar property filters, quick action buttons, and automated site-visit lead generation.
- **Cloud Ready:** Fully dockerized and optimized for zero-cost deployment on Streamlit Community Cloud.
